# 庄子选读 · 自己搭的读书站

一个纯本地的静态小站，不花哨，专门用来"读得下去"。

## 怎么打开

三种都行，挑一个：

1. **双击 `index.html`** —— 最省事，直接进浏览器。
2. **起本地服务**（推荐，个别浏览器在 `file://` 下会限制本地存储）：
   ```
   cd D:\dsh休闲区\zhuangzi-site
   node server.js
   ```
   然后打开 http://127.0.0.1:8420

## 里面有什么

| 篇目 | 为什么选它 |
| --- | --- |
| 逍遥游 | 总纲：什么叫真正的自由 |
| 养生主 | 最实用：庖丁解牛，怎么不把自己磨坏 |
| 齐物论（节选） | 只取了最好懂的"庄周梦蝶" |
| 十个钩子 | 不读原文也能记住的核心意象 |

每段都是**上原文、下白话**，23 段原文一共约 1350 字，半小时能刷完。

## 页面功能

- 左侧目录点击切换篇目，显示各篇读到第几段
- **对照：开/关** —— 只想看原文时可以把白话收起来
- **A+ / A−** —— 调字号（15–30px），手机上自动收一号
- **夜 / 日** —— 深色 / 浅色，默认跟随系统
- 阅读进度条：滚过一整段才算读到，进度自动存在浏览器里，下次打开接着上次那篇
- 键盘 ← → 翻篇，Esc 关目录
- `Ctrl+P` 打印（会去掉所有按钮，适合印出来看）

## 想加新内容

编辑 `data.js`，往 `CHAPTERS` 里追加一个对象就行，格式：

```js
{
  id: "qiuShui",            // 唯一标识，别重复
  title: "秋水",
  source: "《庄子·外篇》",
  summary: "一句话导读",
  tags: ["进阶"],
  segments: [
    { text: "原文一句或一段……", note: "对应的白话翻译。" }
  ]
}
```

改完刷新页面即可，不需要重新构建。

## 文件说明

- `index.html` —— 页面骨架
- `styles.css` —— 样式（护眼米色 / 深色两套）
- `app.js` —— 目录、对照、字号、进度记录
- `data.js` —— **全部内容都在这里**，要改内容只动这个文件
- `server.js` —— 30 行不到的本地静态服务器，可选

原文为公有领域古籍；白话与导读为本地整理。
